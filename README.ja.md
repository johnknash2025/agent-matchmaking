# エージェント・マッチメイキング（構想）

[English](README.md) | 日本語

> 仮の名前です。**まだ構想だけで、アプリもコードもありません。** 議論のために考えを書いたページです。

**ひとことで：** 一人ひとりが、自分がパートナーに何を求めているかを知っている自分専用の AI エージェントを持ちます。まずエージェント同士が話し、両方のエージェントが良い相性だと判断し、さらに本人たちが二人とも同意したときにだけ、二人を紹介します。

## 何が問題か
マッチングアプリでは、写真と短いプロフィールで知らない人を判断し、その先に進まない会話をたくさん始めることになります。本当に大事なこと（価値観、人生設計、二人が実際にうまくやっていけるか）が分かるのは、たくさんの時間と、ときには傷ついた後です。特に結婚を考えている人は、数は少なくても、より良い出会いを求めています。

## なぜやるのか
婚活はつらいものになり、多くの人があきらめています。多くのアプリは人を年収・身長・写真といった短い属性の一覧にしてしまい、二人を本当に引き寄せるもの（会話の流れ、価値観の合い方、一緒にいるときの感じ）を失っています。さらにそのビジネスモデルは、二人がカップルとしてアプリを卒業することではなく、アプリに居続けることに報酬を与えています。

## 役割：仲人ひとり、門番ふたり
| 役割 | 誰の味方か | 何をするか |
|---|---|---|
| **仲人エージェント**（ひとり、中立） | 二人の関係 | それぞれの門番が見せてよいとしたものだけを見て、「この二人は一緒に物語を作っていけるか」を考えます。片方を勝たせる手伝いはしません。 |
| **本人それぞれのローカルエージェント**（すでに本人のもの） | 本人 | 本人の本音を守る門番です。本音は本人の端末に置いたまま、本人が許したものだけを渡します。本人が嫌だと言えば、そこで止まります。 |
| **本人たち** | | 会う、決める、結婚する、子どもを持つかを決める。 |

エージェントは支えるだけで、決めるのは人間です。二つのエージェントが互いに交渉して勝ち負けを争う仕組みではありません。また仲人が、全員の本音を一か所に集めることもしません。

## 仲人は何に対して報われるか
- **片方ではなく二人とも。** 成功とは、二人ともが良かったと言えること、そして関係が続くことです。片方にだけ良いマッチは失敗です。
- **同意は重みづけではなく、越えてはいけない線です。** 仲人がどれほど良いマッチだと考えても、どちらかが嫌だと言えば進めません。どんな点数もそれを覆せません。
- **家族や子どもは、二人とも望むときだけ。** 二人とも子どもを望むなら、仲人はそれがうまくいくよう手伝います（時期、住まい、仕事）。望まないなら、それも良い物語です。
- **社会の目標は、仕組みの外に置きます。** 良い関係が増えれば社会が続いていく助けになるかもしれません。でもそれは期待する結果であって、仲人の報酬ではありません。

### 人口や出生率を直接の報酬にしない理由
- 本人以外の目標のために働くエージェントに、本音を預ける人はいません。
- 子どもを持ちそうかどうかで人を選ぶのは、人を属性で見ることのさらに悪い形です。子どもを望まない人・持てない人や、同性カップルを締め出すことにもなります。
- 外の目標を本人の望みより上に置くのは、操作です。
- 「社会が続くこと」は測れないので、エージェントは代わりの数字（結婚数・出生数）を追いかけることになります。アプリが利用時間を追いかけるのと同じ落とし穴です。

## アイデア
1. **一人にひとつ、自分のエージェント。** 会話を通じて、その人が何を大事にしているか、何は譲れないか、どんな話し方が好きかを学びます。繊細な情報は本人のエージェントの手元に残ります。
2. **まずエージェント同士が会う。** 二つのエージェントが、それぞれの本人が望むことを段階的に照らし合わせます。各段階で必要なことだけを共有します。合わない組み合わせのほとんどはここで静かに終わり、誰も断られたと感じずに済みます。
3. **決めるのは本人。** 両方のエージェントが良い相性だと判断したら、それぞれの本人に「なぜ」を短く説明し、紹介を受けるかを本人が決めます。同意なしに相手に何かが伝わることはありません。
4. **実在の人と、実際に会う。** 一人ひとりが実在の人間であることを確かめ、実際に会うことを目指します。エージェントはその段取りを手伝いますが、関係そのものの代わりにはなりません。

## 原則
- **すべての段階で同意を取る。** 情報をさらに共有するのも、紹介されるのも、会うのも、それぞれ本人の「はい」が必要です。
- **エージェントは本人のふりをしない。** ほかの人間との会話で、エージェントが書いたときはそう明かします。
- **居続けさせる仕掛けを使わない。** 成功とは良い紹介であって、アプリでの滞在時間ではありません。
- **データは最小限。** 各段階で必要最小限だけを共有し、すべてを消せるようにします。
